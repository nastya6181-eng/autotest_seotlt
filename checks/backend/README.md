# Бэк: как сервер отвечает

Проверки HTTP-запросами, без браузера. Доступа к коду и серверу сайта у нас нет, поэтому «бэк» — это всё, что видно снаружи по ответам сервера: коды, редиректы, скорость, AJAX-обработчики, приём форм, полнота данных в карточках.

> Статус: **каркас**. Папка, формат описания и план проверок готовы, кода и пайплайна пока нет.

## Что будет проверяться

| Проверка | Что ловит |
|---|---|
| Коды ответов и редиректы | страница отвечает не тем кодом; разные адреса одной страницы (со слэшем и без); редирект-цепочки |
| Время ответа | TTFB выше порога по ключевым страницам |
| Ошибки сервера в ответе | тексты ошибок PHP / Битрикса, отладочный вывод в HTML |
| AJAX-обработчики | адреса, которые дёргает фронт (календарь, фильтры, «показать ещё»): отвечают, формат ответа не сломан |
| Параметры | кривые `?date=`, `?PAGEN_1=`, фильтры не роняют сервер и не плодят бесконечные страницы (см. issue #44) |
| Полнота данных | у каждой меры поддержки есть контакты и сроки, у резидента — описание, у новости — дата |
| Отправка форм | сервер принимает и валидирует заявку — **только на тестовом стенде или с тестовой пометкой** |
| Базовая безопасность | не открыты служебные пути, есть заголовки безопасности — **только с разрешения владельца сайта** |

Технические проверки, которые уже есть в общих проверках (SSL, http→https, 404, sitemap — `checks/content/tech.py`), остаются там.

## Где описание для сайта

```
sites/<ключ>/backend/
  endpoints.yml     страницы и AJAX-адреса: ожидаемый код, порог времени, формат ответа; формы
```

Формат — в примере `sites/_template/backend/endpoints.yml`.

## Что нужно узнать у владельца сайта до начала

- есть ли тестовая копия сайта (staging) — без неё формы проверяются только до кнопки «Отправить»;
- список форм и куда уходят заявки;
- можно ли делать базовые проверки безопасности.

## Как это ляжет дальше

| Что | Где |
|---|---|
| CLI слоя | `checks/backend/backend_checks.py` |
| общий код | `checks/backend/`; запросы — через `throttle` (бережный темп, как у обхода) |
| пайплайн | `.github/workflows/backend-checks.yml`: ручной запуск, матрица по сайтам |
| зависимости | `requirements.txt` (браузер не нужен) |
