`_template/` — заготовка для нового сайта.

## Новый сайт

1. **Секрет.** Владелец репозитория заводит `SITE_<КЛЮЧ>` (Settings → Secrets and variables → Actions → Secrets), значение `https://адрес/ [опции]`. С этого момента сайт попадает в общие проверки.
2. **Папка.** Скопировать `_template/` в `projects/<ключ>/` (ключ — имя секрета без `SITE_` в нижнем регистре, `_` → `-`), заполнить `README.md` (паспорт), удалить файлы слоёв, которые пока не нужны.
3. **Строка в таблице выше.**
4. **Метка** `site:<ключ>` в Issues (Labels → New label) — ею помечать все задачи по сайту.

## Как найти всё про один сайт

| Что | Где |
|---|---|
| настройки и описание проверок | `projects/<ключ>/` |
| задачи | Issues → фильтр по метке `site:<ключ>` |
| прогоны | Actions → прогоны с названием «… · <ключ>» (или «… · all» — все сайты) |
| отчёт одного прогона | прогон → задание `tests (<ключ>)` / `design (<ключ> · <страница>)` → Summary и шаги «Тест: …» |
