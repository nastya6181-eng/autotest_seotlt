## Особенности

- **Ограничение частоты запросов.** Битрикс «Контроль активности» на 2,5+ запросах в секунду отвечает 503 «You have made too many requests per second» и банит IP примерно на 5 минут. Поэтому в секрете — `max_rps=0.8 cooldown=330`: прогон медленный, зато без ложных «битых» ссылок.
- **robots.txt закрывает весь сайт** (`Disallow: /`). Обход согласован с владельцем — в секрете `ignore_robots=true`. Если сайт рабочий, а не тестовая копия, robots.txt стоит исправить: сейчас сайт не попадает в поиск.
- **Лимит страниц** — `max_pages=150`: с тротлингом 300 страниц не укладываются в час.
- **Каталог с фильтрами и пагинацией** (`/filter/clear/apply/`, `?PAGEN_1=`) — та же ловушка для обхода, что календарь у Иннотеха (issue #44).

Значение секрета целиком (для справки, сам секрет не виден никому после сохранения):
```
https://<адрес>/ max_pages=150 delay=0.5 max_rps=0.8 cooldown=330 ignore_robots=true
```
