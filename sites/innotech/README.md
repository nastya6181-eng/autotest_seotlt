## Особенности

- **Календарь мероприятий бесконечен** (`/calendar/?date=…`): без исключения обход тратит на него большую часть лимита страниц. Временное решение — `exclude: 'calendar/\?date='` в `content/project.yml` (issue #43), общее — защита обхода (issue #44).
- **Яндекс.Карты** отвечают 403 без Referer сайта — это не поломка (issue #34).
- **ВК режет ботов** с серверов GitHub — для проверки ссылок это ложное срабатывание (issue #34).
- **Макет главной** — 1600 px, Montserrat; 130 из 302 текстов в динамических зонах (новости, слайдеры, календарь).
